# BinCalc — Binary Calculator & Converter

> Calculate · Convert · Understand

A clean, educational binary calculator built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step — just open and use.

🔗 **Live:** https://bincalc-ryankorir00-4850s-projects.vercel.app

---

## Features

| Feature | Description |
|---|---|
| Binary Arithmetic | Addition, subtraction, multiplication, division |
| Step-by-Step | Carry rows, bit-by-bit breakdown for every operation |
| Multi-base Results | Every result shown in Binary, Decimal, Hex, and Octal |
| Live Converter | Type in any base — Binary, Decimal, Hex, or Octal — rest update instantly |
| Bitwise Operations | AND, OR, XOR, NOT with colour-coded truth tables |
| Calculation History | Last 20 operations, clearable |
| Copy Button | One-click copy of any result |
| Responsive | Works on desktop, tablet, and phone |
| Input Validation | Helpful inline errors for invalid input |
| Keyboard Support | Press Enter to calculate |

---

## Stack

- **HTML5** — semantic markup, ARIA roles for accessibility
- **CSS3** — custom properties, CSS Grid, no frameworks
- **Vanilla JS** — zero dependencies, runs offline after first load
